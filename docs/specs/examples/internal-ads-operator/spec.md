# Internal advertising operator

The user requests an internal reconstruction of Adspirer's workflow using REA,
callable from AI clients through MCP or HTTP. This is an independently deployed
example in the user's fork, not a new REA inspection capability.

Requirements: one shared typed application layer for REST, remote Streamable HTTP
MCP and local stdio; configured account allowlist; honest connector capabilities;
normalized reporting with currency and coverage; keyword research; paused Google
Search and Meta Traffic campaign bundles; persistent brand context; immutable
change previews and separate operator approval; durable execution receipts and
ambiguity recovery; encrypted OAuth tokens; Docker deployment and client examples.

Acceptance: public API/MCP flow, unauthorized requests, schema validation, budget
limits, approval integrity/expiry, account identity, concurrency/idempotency,
restart recovery, partial writes and provider payloads are tested. Real ad-account
verification requires operator credentials and is explicitly unverified here.
No advertising spend is authorized by this build request. No Adspirer private
code, credentials or authenticated product access is available. No claim of all
400+ proprietary tools or unrestricted AI-client compatibility.
